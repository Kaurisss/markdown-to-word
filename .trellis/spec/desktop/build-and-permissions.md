# Build And Permissions

## Sidecar Binary

The Python backend is packaged as a Tauri sidecar named `binaries/md2word` in `src-tauri/tauri.conf.json`. Platform-specific filenames are generated by `scripts/build-python.js`, for example `md2word-x86_64-pc-windows-msvc.exe`.

Build flow:

- `pnpm run build:backend` runs PyInstaller using `md2word.spec`, then copies the executable into `src-tauri/binaries/`.
- `pnpm run build:tauri` runs `build:backend`, `build`, and `tauri build`.
- `pnpm run build:installer` runs Inno Setup through `scripts/inno-setup.iss`.

When changing backend dependencies, update `backend/requirements.txt` and verify PyInstaller still bundles correctly.

## Capabilities

`src-tauri/capabilities/default.json` grants:

- Core window controls used by custom chrome.
- `core:webview:allow-create-webview-window` for settings and AI config windows.
- Dialog permissions for save/open confirmations.
- Shell `open` for external links.
- Shell sidecar execution for `binaries/md2word` with `--input`, `--output`, and `--config-file`.
- App cache read/write/remove for temporary Markdown and config files.
- Broad `$HOME/**` fs scope for user-selected file paths.

Keep capability permissions as narrow as the actual API calls allow. If adding a new Tauri plugin call, add the matching permission and cite the front-end file that uses it.

## Export Temp Files

The front-end export path writes temp input and config files to `BaseDirectory.AppCache`, executes the sidecar, then removes both files. This relies on app-cache fs permissions.

Reference:
- `src/features/export/pythonBackend.ts`
- `src-tauri/capabilities/default.json`

Do not pass the JSON config directly on the command line; current code uses a config file to avoid UTF-8 command argument issues with Chinese text.

## Generated Front-End Assets

`scripts/generate-css-tokens.js` reads `src/design/tokens.json` and rewrites the `:root` and `.dark` token blocks in `src/index.css`.

This script runs before `pnpm run dev` and `pnpm run build`. Treat `tokens.json` as source of truth for token values.
